# かんじ けいさん

小学1年生向けの漢字学習アプリ(80字)。`index.html` をブラウザで開くだけで遊べます。

## がめんの つかいかた
下のメニューで、4つの画面を切りかえる。右上の ⭐ は、いまの数。🔊 で音、⚙️ で設定。
- 🏠 **ホーム:** ペット、れんぞく日数、きょうの ミッション、「べんきょう する」ボタン、「つづき」(前回と同じ設定でそのまま始める)、まちへの入り口
- 📚 **べんきょう:** ①やる勉強を選ぶ → ②問題数(5・10・20・ずっと)を選ぶ → はじめる。選んだ内容は覚えておく
- 🏘️ **まち:** 建物を建てる・レベルアップ・毎日のごほうび・なかま
- 📖 **ずかん:** 80字のずかん、バッジ、おみせ

べんきょう中は、上に「何問目か」の進み具合が出て、「やめる」(2回押し)で途中で終われる。決めた問題数が終わると、けっか画面(⭐3段階、1回で正解した数、あたらしい字、ベストコンボ、ゲットした⭐)が出て、「もういちど」「ほかの べんきょう」「ホームへ」を選べる。途中でやめても、1問でも終わっていればけっかを出す。

## モード(1年生の漢字 80字)
- 🔢 けいさん: 漢字のたし算・ひき算(一〜十)
- ↔ はんたいことば: 上↔下、大↔小、左↔右、入↔出、男↔女
- 🖼️ えから かんじ: 絵から漢字を選ぶ。選ぶと絵が漢字に変身(47字。林=🌲🌲、森=🌲🌲🌲 など)
- 📖 よみクイズ: 80字ぜんぶの読みを選ぶ
- 📝 ぶんの かんじ: ひらがなの短い文の空欄(＿)に入る漢字を選ぶ(80字ぜんぶ)
- 🎲 80じ ミックス: 80字ぜんぶが、上のモードのうち出せるものにランダムに混ざって出る。まだ載っていない字と苦手な字を多めに出す

## 共通の流れ
正解 → かきじゅんガイド付きの書き取り → ずかん登録。ずかんがたまるとペットが進化(🥚→🐣→…→🦄、80字で🦄)。
間違えた字は出やすくなる(苦手の復習)。進み具合はブラウザ内(localStorage)に保存。

## ゲーム要素
- 🔥 **コンボ:** 1回目で正解を続けると増える(5コンボごとに⭐+1)。まちがえるとリセット
- 📅 **れんぞく日数:** 毎日あそぶと増える(3・7・14・30日で⭐ボーナス)。1日あくと1に戻る
- 🎯 **きょうの ミッション:** 毎日3つ(日付で決まる。1回で正解8問、3つのあそびかた、かきとり5字、コンボ5、あたらしい字2字)。1つ達成で⭐+2、3つぜんぶで⭐+3
- 🏅 **バッジ:** 16種(ずかんの字数、コンボ、れんぞく、リベンジ、かきとり、ミッションなど)。ゲットで⭐+2
- 🛍️ **おみせ:** ⭐でペットのアクセサリー(リボン・シルクハット・おうかん・サングラス・マフラー・おはな・サッカーボール・まほうの つえ)を買って、つけかえられる
- きろくのコードには、おみせ・バッジ・⭐も入る(コンボと今日のミッションは入らない)

## かんじの まち
斜め上から見た四角いフィールドに、建物やかざりを、すきな場所に置いて、自分だけの街を作る。
- **フィールド:** はじめは6×6マス。ずかんが20字ふえるごとに広がる(最大10×10)。ひろがっても、置いたものはそのまま
- **たてもの(24種類):** ⭐で買って、フィールドに置く。大きさは1×1〜3×3マス。2〜4段階にレベルアップする(絵が大きく変わる)。その建物に結びついた漢字をゲットすると、買えるようになる。まだ開かない建物は「？？？」と出て、必要な漢字が見える
- **かざり(16種類+みち):** ベンチ、花、木、ちょうちん、ほうせき、いせきなど。⭐1〜10で、何個でも置ける。「みち」は、マスをタップで⭐1で地面に引ける(もう一度タップで消す。⭐は戻らない)
- **置きかた:** 下の一覧から選ぶ → 買う(または「おく」) → フィールドのマスをタップすると、置く場所が出る(緑なら置ける、赤だと置けない) → 「ここに おく ✓」。重なるところ、はみ出すところには置けない
- **置いたあと:** 建物やかざりをタップすると、「うごかす」「はんてん」(左右)「しまう」(買ったものは残る)と、建物は「レベルアップ」ができる。背の高い建物は、上のほうをタップしても選べる
- **なかま:** ずかんが一定の数になると、キャラクター(9人)が仲間入りして、フィールドを歩き回る。タップするとセリフ
- **毎日のごほうび:** たからばこをタップで、街の大きさに応じた⭐(1日1回)
- きろくのコードに、置いた場所・かざり・みちも入る。置き場所のない古いコードは、自動で並べる
- 絵は `img/` の画像(元の絵を縮小した WebP、合計約2.5MB)。地面は、コードで描いている

## おぼえなおし
- 1回でもまちがえたら、ほかの答えを選んで先へ進める。ただし**ずかんには載らない**(⭐も増えない)。
- 正解のあと「おぼえなおし」カード(字・読み・絵)と、おてほん付きの書き取りに進む。
- その字は 🔁 マークでずかんに「おぼえなおし中」と出て、**数問あとに もう一度出題**される(「🔁 リベンジ!」)。
- リベンジで**1回目に正解**するとずかんに載り、⭐ボーナス。まちがえたら間隔をのばして、また後で出る(最大9問あと)。
- 出題できないモードでは出ない(例: 絵のない「五」は「えから かんじ」では出ない)。別のモードで1回目に正解しても解消される。

## スマホで あそぶ(おすすめ: GitHub Pages)
claude.ai の公開ページは、枠(iframe)の中で動くため、Safari で約1週間さわらないと記録が自動で消されることがある。
**独立した URL で開き、ホーム画面に追加したアプリは、この自動削除の対象外**(WebKit の仕様)なので、こちらを使う。

1. GitHub のリポジトリで **Settings → Pages → Build and deployment**
2. **Source: Deploy from a branch**、**Branch: main / (root)** を選んで Save
3. 1〜2分後に `https://<ユーザー名>.github.io/kouzou/` で開ける
4. iPhone: Safari でそのURLを開き、共有ボタン → **ホーム画面に追加**。以後はホーム画面のアイコンから開く
   (ホーム画面アプリは、Safari や claude.ai のページとは**保存場所が別**。記録は引き継がれないので、必要なら ⚙️ のコードで移す)

## きろくの ほぞんと バックアップ
- 進み具合は、ブラウザの localStorage と IndexedDB の2か所に保存する。どちらか片方が消えても、残った方から自動で復元する。
- ブラウザの設定(Safari は約1週間さわらないと消す、プライベート画面、ホーム画面アプリとブラウザで保存場所がちがう、など)で両方消えると、復元できない。
- そのため、⚙️ に「きろくの バックアップ」を用意した。**コードを つくる**→ コピー → メモなどに保存。消えたら **このコードで もどす**(いまの記録に「あわせる」。あたらしいほうを残す)。
- 保存できない画面(プライベート画面など)で開くと、画面の上に警告を出す。

## こうかおん
音声ファイルは使わず、ブラウザの WebAudio でその場で作る(正解=ド・ミ・ソ、やさしい低い音のまちがい、画ごとに高くなる音、完成・進化のファンファーレ)。
画面右上の 🔊/🔇 で、効果音と読み上げをまとめてオン・オフできる。

## かきじゅんガイド
- 次に書く画のはじまりに ●(番号つき)が出て、最初の画は筆の動きのおてほんが流れる。
- 1画ずつ判定。合っていれば、きれいな線に置きかわる。
- まちがいは叱らず、理由に合わせて声かけする(順番ちがい・むきがはんたい・はじまりが ちがう・みじかい・形が ちがう)。
- まちがえたら おてほんを自動で再生。4回つづけて むずかしいときは「いっしょに かこうね」と代わりに書いて次へ。
- 「おてほん」「やりなおし」ボタンつき。
- **はね・はらい・とめ:** 次の画の終点に「はね」「はらい」「とめ」と表示。
  はねは線の最後の曲がり、はらい・とめは最後の指の速さ(はらい=速いまま、とめ=ゆっくり)で見ている。
  **ほめるだけ**で、まちがいとは判定しない(はね・はらいの✨が全部とれると⭐ボーナス)。
  指の速さは実機での確認が足りないので、あくまで目安。
- **⚙️ せってい(おうちのひと用):** むずかしさ(やさしい/ふつう/きびしい)、おてほんの自動再生、はね・はらい・とめのチェック、
  判定ログ(ずれ具合の数値を画面に出す。実機で調整するとき用)、きろくの消去。
- 判定は、書いた線と おてほんの線を一定の点数で取り直して、距離・始点・終点・むき・長さを比べる(`index.html` の `judge`)。
  似た形の画(「男」の縦線どうしなど)は、順番を入れかえても通ることがある。
